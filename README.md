# TCP 文件传输工具

基于 TCP Socket 套接字实现的跨主机文件传输工具，支持服务端向客户端批量发送文件。

## 功能特性

- **可靠传输**：利用 TCP 协议确保文件传输的可靠性、有序性和完整性
- **多客户端支持**：服务端采用多线程设计，可同时处理多个客户端连接
- **批量文件发送**：服务端可一次性指定多个文件，按顺序发送给客户端
- **传输进度显示**：客户端实时显示文件接收进度
- **文件属性保持**：传输时包含文件名和大小信息

## 编译方法

### 服务端编译
```bash
gcc TCP_File_Trans_Server.c -o server -lpthread
```

### 客户端编译
```bash
gcc TCP_File_Trans_Client.c -o client
```

## 使用方法

### 1. 启动服务端

服务端启动时需要指定要发送的文件列表（一个或多个文件）：

```bash
./server file1.txt file2.jpg ...
```

服务端会：
- 监听本机 9413 端口
- 等待客户端连接
- 每个客户端连接后，依次发送所有指定文件

### 2. 启动客户端

客户端启动时需要指定服务端的 IP 地址：

```bash
./client <服务端IP地址>
```

客户端会：
- 连接到指定的服务端
- 接收服务端发送的所有文件
- 保存到当前目录
- 实时显示接收进度

## 通信协议

传输流程：

1. **建立连接**：客户端连接到服务端的 9413 端口
2. **发送文件信息**：服务端先发送 `file_info_t` 结构体，包含：
   - 文件名（最多 100 字节）
   - 文件模式
   - 文件大小（64 位无符号整数）
3. **发送文件数据**：服务端以 1KB 为单位发送文件内容
4. **循环发送**：重复步骤 2-3，直到所有文件发送完毕
5. **断开连接**：服务端关闭连接

## 技术细节

- **端口**：默认使用 9413 端口
- **缓冲区**：1KB (1024 字节)
- **线程模型**：每个客户端连接对应一个独立线程
- **信号处理**：忽略 SIGPIPE 信号防止程序崩溃
- **地址复用**：服务端启用 SO_REUSEADDR 支持快速重启

## 注意事项

1. 确保服务端指定的文件存在且可读
2. 确保网络通畅，防火墙允许 9413 端口通信
3. 文件名长度不超过 100 字节
4. 客户端当前目录需要有写入权限
